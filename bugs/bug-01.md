# BUG-01: POST /api/books нь буруу JSON биетэй хүсэлтэд 400 биш 200 OK буцаадаг

Орчин: Уншлагын жагсаалт v2.0, Microsoft Edge 155.0.4283.60 (Official build) (64-bit), Windows 11, 2026-10-17 (API: curl.exe)

Урьдчилсан нөхцөл: node app.js-ийг шинээр асаасан (анхны 3 ном)

## Дахин гаргах алхам

1. `node app.js`-ийг шинээр асаа.
2. PowerShell дээр ажиллуул:
   `curl.exe -si -X POST localhost:3000/api/books -d "буруу оролт"`
3. Хариуны статусын мөр болон биеийг хар.

Хүлээгдэж байсан: Спецификац: «API: буруу JSON биетэй POST хүсэлтэд 400 алдаа буцаана.» Тиймээс `HTTP/1.1 400 ...` статус.

Бодит үр дүн: `HTTP/1.1 200 OK`, бие нь `{"result":"OK"}`. Хүсэлт буруу байсан ч амжилттай гэж мэдэгддэг.

Ноцтой байдал: Major. Дуудагч (клиент) өгөгдөл хадгалагдсан гэж андуурч болно, мөн алдааг илрүүлэх боломжгүй.
