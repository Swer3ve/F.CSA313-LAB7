# BUG-03: Хүснэгтэд он тоо таслалтай харагддаг (1971 → 1,971)

Орчин: Уншлагын жагсаалт v2.0, Microsoft Edge 155.0.4283.60 (Official build) (64-bit), Windows 11, 2026-10-17

Урьдчилсан нөхцөл: node app.js-ийг шинээр асаасан (анхны 3 ном)

## Дахин гаргах алхам

1. `node app.js`-ийг шинээр асааж http://localhost:3000 нээ.
2. Хүснэгтийн «Он» баганыг хар.

Хүлээгдэж байсан: Спецификац: «Он ... хүснэгтэд энгийн тоогоор (жишээ нь 1999) харагдана.»

Бодит үр дүн: Он `1,971`, `2,008`, `1,999` гэж мянгатын таслалтай харагдана.

Ноцтой байдал: Minor. Өгөгдөл зөв хадгалагдсан, харин харагдац нь оныг тоо хэмжээ мэт харуулж, ойлгомжгүй болгоно.
